# Diretório de Loaders / Programmers EDL

Este diretório é reservado para os arquivos programmer do Qualcomm Firehose (`prog_emmc_firehose_xxx.elf`, `prog_ufs_firehose_xxx.elf` ou `.bin`).

## Aviso Legal & Licença

Por motivos de propriedade intelectual e conformidade de licença:
**Nenhum loader ou programmer proprietário da Qualcomm é distribuído diretamente no repositório ou empacotado dentro do APK.**

## Como Utilizar

1. Obtenha o programmer correspondente ao chipset e memória do seu aparelho (ex: `prog_firehose_ddr_sm8250.elf`).
2. Transfira o arquivo para o armazenamento do seu dispositivo Android (ex: pasta `Download`).
3. No aplicativo **Qualcomm EDL Tool**, abra a aba **Programmer** e clique em **[Selecionar Programmer]**.
4. O Storage Access Framework (SAF) permitirá selecionar o arquivo `.elf` ou `.bin` diretamente do seu armazenamento.
